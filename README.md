# Front Pages

A collection of three static web pages that turn visual designs into code using HTML and CSS.


| Coffee Vibe | Two-column hero, overlapping circular images, stats cards, Playfair Display and Poppins fonts |
| Discover Design | Large hero heading, 3D art gallery images, content blocks, Lato font |
| Landing Page | "All your ideas in one place" landing page with card sections and social icons |



## Tech Stack
HTML5, CSS3 (Flexbox, CSS Grid), Google Fonts

## Project Structure
```
front_pages/
├── coffee/        # index.html, style.css, image/
├── discover/      # index.html, style.css, gallery/
└── landing page/  # index.html, styles.css, images/
```

## Run Locally
```bash
git clone https://github.com/SanyaSajid/front_pages.git
cd front_pages
```
