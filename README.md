# Front Pages

A collection of three web pages designed in Figma (UI/UX, layout and typography) and then developed with HTML and CSS.

| Coffee Vibe | Two-column hero, overlapping circular images, stats cards, Playfair Display and Poppins fonts |
| Discover Design | Large hero heading, 3D art gallery images, content blocks, Lato font |
| Landing Page | "All your ideas in one place" landing page with card sections and social icons |

## Tech Stack
Figma (UI/UX design), HTML5, CSS3 (Flexbox, CSS Grid), Google Fonts
